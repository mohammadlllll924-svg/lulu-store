# متجر عالم لولو للصغار

متجر Flask للمنتجات الرقمية، مع حفظ ملفات PDF خارج مجلد `static` وتسليمها عبر مسار محمي.

## الحماية والتسليم

- لا تُعرض روابط ملفات PDF في صفحات المنتجات أو صفحة النجاح العامة.
- ينشئ المتجر طلباً بحالة `pending` ورمز تنزيل عشوائياً. مسار التنزيل يرفض أي طلب غير مدفوع أو يحمل رمزاً غير صحيح.
- صفحة العودة من Shopier ليست إثباتاً للدفع. بعد التأكد من العملية في لوحة Shopier، غيّر حالة الطلب إلى «مدفوع» من `/admin`. لن يظهر رابط التنزيل قبل ذلك.
- ارفع ملفات PDF من شاشة إضافة/تعديل المنتج في لوحة المدير. تُحفظ الملفات في `PRIVATE_DOWNLOADS_DIR` باسم داخلي عشوائي.
- لا تضع ملفات العملاء في `static/` ولا ترفع مجلد `private_downloads/` إلى GitHub.

## إعداد Render

اضبط `ADMIN_PASSWORD` و`SECRET_KEY` بقيم قوية في إعدادات البيئة. أضف Render Persistent Disk وثبّته على `/var/data`، ثم اضبط:

```text
PRIVATE_DOWNLOADS_DIR=/var/data/private_downloads
DATABASE_PATH=/var/data/store.db
SESSION_COOKIE_SECURE=true
```

بعد النشر، افتح `/admin`، وارفع ملفات PDF لكل منتج، وأدخل رابط الدفع الحقيقي في Shopier. لا تُفعّل منتجاً للبيع قبل وجود الملف ورابط الدفع.

## ملاحظة تكامل الدفع

روابط الدفع الحالية هي روابط Shopier المُعدة مسبقاً؛ لذلك لا يثق المتجر في مجرد زيارة صفحة النجاح ولا يسلّم الملف تلقائياً. يجب التحقق من كل عملية في لوحة Shopier وتغيير حالة الطلب يدوياً. يمكن إضافة تأكيد آلي لاحقاً بعد تهيئة تكامل Shopier موثق ومطابقة webhook/الإشعار الموقّع مع رقم الطلب والمنتج؛ لا تضف رابطاً عاماً إلى الملف كبديل.

## التشغيل محلياً

```bash
pip install -r requirements.txt
cp .env.example .env
flask --app app run
```

افتح `http://127.0.0.1:5000` للمتجر و`http://127.0.0.1:5000/admin/login` للوحة الإدارة.

## اختبار الحماية

```bash
python -m unittest discover -s tests -v
```

## تنبيه بشأن الملفات المنشورة سابقاً

كانت ملفات PDF موجودة سابقاً في مجلد `static/downloads` داخل المستودع. حذفها من الإصدار الحالي يوقف المسار المباشر بعد نشر التحديث، لكنه لا يمحو نسخها من commits التاريخية في مستودع GitHub العام أو من النسخ التي سبق تنزيلها. اعتبر النسخ المنشورة مكشوفة؛ إزالة الملفات من كامل تاريخ Git تتطلب إعادة كتابة السجل وforce-push وقد تؤثر في نسخ المستودع الأخرى.
